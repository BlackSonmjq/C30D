# 芒果击打状态机仿真

在仓库根目录执行：

```powershell
uv run --with unicorn --with pyelftools python tests/mango/run_tests.py
```

默认使用 `D:/Keil_v5/ARM/ARMCC/bin` 中的 ARMCC 5 工具链；其他安装路径可通过环境变量 `ARMCC_BIN` 指定。构建产物写入本目录 `.build/`，不提交 Git。

测试直接编译生产代码中的协调任务、推杆任务和测距任务，通过 Unicorn 执行 ARM 指令。FreeRTOS 调度、步进定时器、GPIO 和传感器底层由桩函数模拟，不连接或驱动实物。

当前 14 组场景覆盖：

- 四个芒果编号与 left/right、同编号推杆的对应关系，以及忙碌请求拒绝。
- 停止前进时最后一个 STEP 边沿的计数，以及反向等脉冲返程。
- 重复执行同一编号，初始距离已到 150 mm 时不复用上轮计数。
- 推杆输出实际拉高后计满 5 秒，确认拉低后才允许返程。
- 首次测距超时、前进中测距失效、脉冲上限、推杆失败和运动超时。
- 返程启动失败或途中停止时锁定故障，系统节拍回绕时正常计时。
- PA2、PA3、PA6、PA7 四路 XSHUT 互斥切换、全关及过期数据失效。

断言中的中间等待会重复执行，因此检查次数大于场景数量。仿真通过不能证明实物不失步或准确回到机械原点，现场联调应以实际机构表现为准。
