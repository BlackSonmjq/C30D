# 两路 A4988 引脚接口

DIR 使用 3.3 V GPIO 推挽输出；STEP 空闲时为低电平，需要运动时分别由 TIM12、TIM8 输出定时器 PWM 脉冲。`systemInit()` 调用 `StepperMotor_Init()` 初始化底层 A4988 引脚和两个定时器。两路 STEP 均不会自动产生脉冲。

| 驱动器 | DIR | STEP | EN |
| --- | --- | --- | --- |
| Left | PB14 | PB15 | 外部接线控制 |
| Right | PC7 | PC8 | 外部接线控制 |

初始化电平：两路 DIR=低、STEP=低。两路 EN 都不由 STM32 控制；A4988 的 EN 为低电平有效，必须在外部给两个 EN 提供确定电平。左路 STEP 为 PB15/TIM12_CH2，右路 STEP 为 PC8/TIM8_CH3；此模块占用 TIM12 和 TIM8，不能再用它们运行舵机或遥控输入。PC6、PC9 不再由此模块配置或驱动。

底层引脚接口见 [a4988.h](a4988.h)，独立步进电机库见 [stepper_motor.h](stepper_motor.h) 和 [stepper_motor.c](stepper_motor.c)：

```c
A4988_SetDir(A4988_MOTOR_Left, 1); // DIR 输出高电平；实际正反向取决于接线
A4988_Step(A4988_MOTOR_Left);      // STEP 产生一个上升沿，即一步/一个微步
StepperMotor_SetSpeed(A4988_MOTOR_Left, 4999);    // 匀速目标约 200 脉冲/秒（参数仍为 ARR）
StepperMotor_MovePulses(A4988_MOTOR_Left, 800);  // 阻塞式运动：DIR 高，800 个脉冲
StepperMotor_MovePulses(A4988_MOTOR_Left, -800); // DIR 低，800 个脉冲
StepperMotor_Disable(A4988_MOTOR_Left);          // 停止 STEP PWM，不切断电机保持电流
```

`A4988_Step()` 保留为 GPIO 阻塞式单脉冲接口，只能在该路 PWM 停止时使用。`StepperMotor_MovePulses()` 使用定时器单脉冲 PWM，CCR 设为当前周期的一半，产生约 50% 占空比的 STEP 脉冲；正数 DIR 高、负数 DIR 低，0 不运动；返回完成的脉冲周期数。每段前后最多 200 脉冲加减速，周期从 20 ms 变化到设定的匀速周期。达到目标后自动调用 `StepperMotor_Disable()`，将 STEP 保持低电平；也可从另一任务调用它来停止当前运动。该函数只停止脉冲，A4988 的 EN 仍由外部接线控制，电机可能继续保持力矩。每个电机同一时刻只能由一个任务调用运动接口；需要两路同步运动时还需额外协调。

`StepperMotor_SetSpeed(motor, arr)` 用于分别设置两路目标转速，须先调用 `StepperMotor_Init()`；参数仍为 ARR 值。定时器计数频率为 1 MHz，因此目标脉冲频率约为 `1000000 / (arr + 1)` Hz；默认 `arr=4999`，即 200 脉冲/秒。已移除软件最高、最低速度限制，`arr` 仍为 16 位无符号数；成功返回 `1`，无效电机或 `arr=0` 返回 `0` 且不改配置。`arr=999` 对应约 1 kHz，`arr=99` 对应约 10 kHz，`arr=65535` 对应约 15.26 Hz。有效 STEP 脉冲需要非零 ARR；`arr=0` 不能形成有效的定时器脉冲周期。单脉冲模式由更新中断重启下一脉冲，实际频率仍含中断响应和处理开销。运动中调用会从后续脉冲开始平滑调整，不会取消既定的脉冲数；目标周期大于 20 ms 时以目标周期启动，不再从更快的 50 Hz 起步。实际机械转速还取决于电机整步数及细分档位。测试速度由测试程序实际传给 `StepperMotor_SetSpeed()` 的 ARR 决定。

## FreeRTOS 步进任务与抖动排查

当前 `main.c` 创建 `stepper_Task`，不调用独立测试循环。任务以 ARR=99、ARR=299 交替运行，每段 3200 脉冲，运动完成后 `vTaskDelay` 暂停 1000 ms。按 1.8° 步距角、16 细分计算，每段对应电机轴一圈；不包含减速机构传动比。

原实现由任务等待每个脉冲结束并重启定时器，任务抢占会拉长脉冲间隔。现在 TIM12/TIM8 更新中断负责计数、加减速和启动下一脉冲，任务每次休眠 1 tick 等待结束。仍采用单脉冲模式，避免中断延迟时连续发出未计数的脉冲；CCR 仍为当前周期的一半。保留原有每段前后最多 200 脉冲的加减速。

两个更新中断的抢占优先级为 4，高于当前 FreeRTOS 系统调用阈值 5；中断中不得调用 FreeRTOS API。工程使用 NVIC 优先级分组 4。TIM8_BRK_TIM12 和 TIM8_UP_TIM13 为共享向量，当前仅处理对应步进定时器，不能直接再启用 TIM8 Break/TIM13 等共享中断源。

`StepperMotor_MovePulses()` 必须从开中断、非临界区的任务或裸机主循环调用。禁止在 ISR 或关中断状态下调用。每路同时只允许一个运动调用；另一任务可以调用 Disable 停止。中断处理期间仍有少量软件重启开销，长时间全局关中断及更高/同优先级中断仍可能拉长脉冲间隔。

烧录后建议先架空/空载验证：用逻辑分析仪检查 PB15 的 3200 个上升沿、加减速段、匀速段间隔及至少 1 秒的低电平停顿；再验证 PC8 和带载运行。RTOS 调度可能延长停顿。尚未进行实机波形和机械抖动验证。

独立测试接口 `Stepper_TestLoop()` 保留在 `USER/stepper_test.c`，其 ARR 不影响当前任务。细分需要由驱动器 MS1～MS3 接线设置；测试前确认 EN、电源、共地与限流设置正确。

接线时两块 A4988 的 VDD 接 3.3 V，GND 与 STM32 共地，VMOT 接适合电机的独立电源，并按驱动板要求设置限流和电源去耦。两个 EN 都必须由外部提供确定电平，不能悬空；接低电平会在供电后启用驱动输出。RST、SLP、MS1～MS3 的连接需按所用 A4988 模块和细分需求确定；此接口没有占用这些引脚。

原航模遥控输入和舵机输出已从启动流程移除，自检会跳过舵机阶段。阿克曼车型原先在 PB15 的转向舵机输出也随之停用，使用该车型时需另行安排转向执行器。
