# 测距失效不再立即返程

用户确认K2仅前进一小段后立即返程、没有击打，并要求取消测距一无效就立即返程。本次修改K1～K4共享机构状态机，不改变各编号的到距阈值（K2仍为严格小于60毫米）。

接近阶段无效/过期测距或通道不匹配时，立即停止STEP，进入`STEPPER_RECHECKING_DISTANCE=8`。保持激光通道和任务占有，最多等待2秒；恢复有效且同号后，距离已到位则执行舵机，尚未到位则按剩余脉冲继续。到达复测期限仍未恢复时，以MANGO_SENSOR_LOST返程。

每次暂停都计入最后已输出的STEP边沿，继续运行只申请26000减去累计已发脉冲。返程使用所有前进分段的实际发出总脉冲；若恢复启动失败，仍使用暂停前的准确计数返程。运动总超时在暂停/恢复时不重置，脉冲上限和返程故障锁定保留。新状态追加在枚举末尾，原有状态值不变，OLED任务/机构测距页显示RANGE RECHECK。

USART1新增每次暂停/恢复的单条日志，带测距状态、通道、累计脉冲和剩余脉冲，不在等待循环刷日志。VOFA41通道不变，CH38仍显示整段WORK。

测试：45组机构场景、38项完成任务、64058项检查通过。新增单次/多次测距丢失、最后边沿计数、恢复时已到距、错误通道、恢复启动失败、累计脉冲上限及时钟回绕；持续失效仍停机满复测期限再返程。底盘失败补打10项、完整流程930项回归及EIDE构建通过；尚未烧录或实车验证，不能据此断定此前K2失败一定由测距造成。
