# 遥控对齐与完成通知

当前暂时关闭自动击打，配置为 `VISION_PICK_ENABLE=0` 和 `VISION_STRIKE_ENABLE=0`。继续执行遥控、自动对齐与对齐后的基础停车保持。对齐速度为 0.08～0.18 m/s。下表记录重新启用完整击打流程后的状态。

自动对齐需要树干和绿色果子标记同时有效。仅识别到树干时继续遥控或等待；收到新的 G=0 快照时当周期释放自动对齐控制权并恢复遥控输入，此规则优先于 DONE 的一秒停车保持。树干消失（G 仍为 1）、区域失效或通信过期按原丢失处理停车。再次进入对齐需要重新连续确认有效目标。

| 自动流程状态 | 底盘与视觉行为 |
| --- | --- |
| 等待与对齐 | 连续 3 个新快照同时满足 B=1、G=1、REGION=1～4 后接管。连续 3 个新快照满足绝对偏差不超过 2，完成对中。 |
| 等待触发条件 | 确认同一有效果子区域、四轮停稳、机构就绪，且 S21C 后距新鲜并在 41～79 mm 内。等待窗口为对齐完成后 5 秒。 |
| 停车计时 | 条件满足后连续停稳 1 秒。车轮重新移动、后距失效或果子确认中断会取消本次计时。 |
| 实际击打 | 连续停稳一秒后，按 REGION 请求同号 K1～K4 完整任务，执行激光测距、步进接近、舵机击打、步进返程和激光关闭。期间底盘保持停车，忽略视觉和摇杆干预。 |
| 完成通知 | 数据任务通过 USART1（115200、8N1）发送一次 ASCII 行 `CMD HIT_DONE n`，以 CR LF 结尾，n 为区域 1～4。仅在同号任务成功返程收尾后发送，同时更新 VOFA 完成区域和次数。 |
| 视觉冷却 | 完成通知发出后释放遥控。2 秒内串口 3 正常接收、VOFA 正常显示，控制器跳过此期间的视觉快照。期满后从新帧开始确认。 |

失败任务安全返程后进入两秒冷却，完成次数保持原值；返程故障沿用机构锁定并保持底盘停车。

同一果子只发送一次完成通知。冷却结束后，连续 3 个新的无有效果子快照解除锁存。手动串口 K1～K4 仍可调用原机械任务。

VOFA 使用 33 通道。CH1 为 DX，CH5 为对齐阶段，CH6 为完成流程阶段（0 等待对齐、1 等待条件、2 停车计时、3 发布完成、4 冷却、5 实际击打），CH7 为后距（mm），CH8 为测距新鲜标志。CH11 为最近完成区域（初始 0），CH12 为累计完成次数，每增加 1 表示一轮完成。完成记录持续保留至下一轮完成或复位。转发器终端和 CSV 同步显示这些字段。

自动对齐比例增益为 0.007，横移目标速度限制在 0.08～0.18 m/s。连续三个新快照的 |DX|≤2 后完成对齐。

CH13～CH20 追加 IMU 航向诊断，CSV 保存目标角、实际角、角度误差、角速度、积分补偿、航向锁、姿态新鲜度和阻断位。完整通道说明见 [VOFA 输出](VOFA跑图诊断.md)。

CH21～24、CH25～28、CH29～32 分别为 A/B/C/D 四轮目标速度、编码器实际速度和限幅后 PWM，用于对比地图前端 A/D 与后端 B/C 的运动响应。
