## 修改范围

每个确认地标继续重建下一段起点；墙参考新判点通道重新收集新帧，避免沿用上一段参考面。里程与激光相差大时，只标记本段里程不可信并降速，OLED 显示 `!O`。

墙参考的 500 mm 计划残差、80 mm 预测残差及“计划长度 + 800 mm”轮式行程不再独自触发停车。激光原始值/中值、相邻帧物理变化、近距连续新帧及到点接近证据仍独立验证。大跳变后允许重新验证参考并恢复接近。

保留测距失效停车、最多 30 秒低速搜索、6 秒激光无进展、4 秒回调、70 秒单段和 300 秒全程上限。固定近物读数不能直接切段或倒回。入口/出口纯里程、垄端补偿及其硬行程界限保持，仍须实测标定。

巡航 0.24 m/s、慢速 0.06 m/s、各标定点读数及路线未改变。VOFA 原 0～31 通道保留，追加 32～39 通道，共 40 个 float / 164 字节；波特率和接口不变。

## 查看及回退

在本工程目录运行：

```powershell
git log --oneline --decorate
git diff backup/pre-terrain-nav-20261112 HEAD --stat
git status --short
```

工作区干净时，可切换回修改前分支：

```powershell
git switch main
```

返回修改版：

```powershell
git switch fix/terrain-tolerant-navigation
```

有未提交修改时先另行保存，避免覆盖自己的新改动。切换 Git 分支只改变受版本控制的源码，不会自动回退忽略的 HEX 或控制板固件；切换后须重新编译并下载对应版本。
