# 视觉击打

> 当前实现的统一说明见 [视觉控制逻辑](视觉控制逻辑.md)。本页保留历史说明，当前停车距离、超时及重复次数以统一说明和源码为准。

当前启用对齐后完整击打流程，配置为`VISION_PICK_ENABLE=1`、`VISION_STRIKE_ENABLE=0`。由底盘100 Hz状态机统一提交完整K任务，独立VOFA任务不重复派发。完整时序见[遥控对齐击打流程](遥控对齐击打流程.md)。

| REGION | 原任务 | 执行机构 |
| --- | --- | --- |
| 1 | K1 | 1 号激光、左步进、1 号舵机 |
| 2 | K2 | 2 号激光、左步进、2 号舵机 |
| 3 | K3 | 3 号激光、右步进、3 号舵机 |
| 4 | K4 | 4 号激光、右步进、4 号舵机 |

首次新快照G=1且REGION=1～4即锁定编号，再确认杆子B=1、G=1并对齐DX、按后激光靠近50±3 mm。锁号后跳号或REGION=0不改本轮编号，对齐完成且四轮反馈均≤0.005 m/s连续300毫秒后请求锁定编号K任务；不再等待多数投票或当前编号一致。未取得编号时继续遥控。G=0、通信失效、控制释放及超时清除锁号；机构执行时仍须安全返程才允许释放。成功返程后下一轮重新锁号，安全失败后的有限补打保留本轮编号，每轮仍最多补打1次。限位、超时、失联及返程故障保护继续生效。

成功返程后发送`CMD HIT_DONE n`并增加完成次数。新帧仍有有效绿色果时保持自动并重新确认下一轮；新的G=0立即退出自动，不执行成功后的两秒冷却。缓存、通信中断及G=1但B=0都不能视为果子消失。失败安全返程仍用原冷却策略，返程故障锁定。

手动串口K1～K4入口保留，映射与既有机械流程复用。VOFA CH38/39/40分别显示流程阶段、最近成功区域和成功次数。
