# REGION确认优化

同号连续3帧改为最近5个新快照中同号至少3票。每个证据独立以300毫秒为有效期，避免持续流量维持已经过期的旧票。重复缓存不计数；G/B无效、通信超时、控制阻止或作业被接受时清空窗口。

当前原始REGION必须等于确认的多数编号才允许提交。已确认2号时，单帧3号不会直接启动3号机构，也不会按旧2号击打；3号成为3/5多数才可切换。物理停稳300毫秒与编号确认并行，编号跳动不清除已经满足的物理停稳时间，但当前编号不匹配仍不能提交。

对齐后REGION=0立即释放；此前的多数编号不能填补未知编号。WAIT和HOLD共同受到本次停车等待5秒上限约束，编号持续不确定时也会退出自动。每轮最多补打一次、返程故障锁定、原始45毫米防撞及通信失效保护保留。VOFA41通道及转发器格式不变。

验证：编号及独立派发131项；集成9项，覆盖300毫秒边界恰好跳号不提交、恢复正确编号后使用已满足的停稳时间、持续混号5秒退出；完整击打930项、无编号立即释放128项、失败补打10项、DX/后距判定37项通过，EIDE编译成功。未烧录或实车验证。
