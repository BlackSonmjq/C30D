P01仍用入口里程，Behind_Lidar_1保留作历史对照。P05/P07/P09在完整垄端事件后，由Behind_Lidar_5=2850、Front_Lidar_7=2090、Behind_Lidar_9=1435 mm独立复核停车，三项均已由用户确认实测。详见[通用垄端定位与复核](C:/Users/user_2007/Desktop/芒果机器人/C30D-c30d-develop-import/docs/通用垄端定位与复核.md)。

需要测量里程时，可以保持标定未就绪，用手柄缓慢摆车，查看流程页等待状态下的 `X/Y`。X 正为向车头前进，Y 正为车身左移。两次读数作差得到该段里程；上电后先静置完成原有约 10 秒 IMU 校准，再测量。导航起跑时会重新清零里程和航向。

## 起跑与控制权

1. 检查四路激光方向和接收更新，完成上述标定后，将 `ROUTE_CALIBRATION_READY` 置 1，重新编译下载。
2. 调试模式保持 `ROUTE_DEBUG_MODE=1`。固定摆位后上电静置约 10 秒，确认使能开启、电压正常、轮速为零、机构不忙、CAN 和里程有效，再单击 PE0 起跑。等待期间保留手柄控制。
3. 正式模式将 `ROUTE_DEBUG_MODE=0`。在规定的比赛启动时刻上电 / 复位，程序等待校准和就绪条件满足后自动起跑；此模式上电即由导航占有底盘控制权。
4. 起跑后，导航持续占有控制权。完成或故障时给零速，OLED 保留终态。排除问题后重新摆位并复位开始下一次运行。

`ROUTE_DEMO_ENABLE=0` 可编译回原遥控流程。调试起跑后不会因手柄输入切回遥控。

## 每一段如何推进

编码器每次采集的计数经底盘原有换算恢复为本次位移，再结合持续积分的 IMU Z 轴角速度更新里程。平移直接累计本次位移，IMU 按实际采样时间积分，避免固定 100 Hz 速度再乘实际时间导致重复放大。原来的四轮速度 PI 保留；导航行进时以起跑航向为基准纠正车身角度。

每次确认到点后，记录下一段起点，本段进度 S 重新从零计算；墙/垄端地标只校正运动轴，IMU 航向保持连续。墙参考的新判点通道重新收集滤波新帧，避免把上一段的侧墙或垄面中值当成新段已到点。

墙参考先按编码器粗进度运行，约完成 2/3 时打开 CAPTURE；已连续确认近距新帧且观察到至少 50 mm 激光接近量时，也允许提前开窗，因此编码器少计或冻结不会永远阻止激光接管。有效远回波允许低速搜索近参考，搜索默认最多 30 秒；不能用远回波确认到点。尚未接管且粗进度未达门槛时，连续 6 帧稳定远距可撤销假近物打开的窗口并恢复粗导航。

原始值与三帧中值须相差不超过 80 mm；相邻激光剩余距离的变化须不超过“巡航速度上限 × 新帧间隔 + 30 mm”。正向行进时还检查累计远离趋势。这些判断不依赖编码器位移。连续 4 个可信近距新帧后接管，更新 G = 当前里程 + 激光剩余。首次或跳变后剩余不大于 200 mm，须有至少 50 mm 连续接近证据，否则停车验证，避免固定假近距造成低速挪行、到点或回调。前后/侧向纠偏也要求在各自标定范围内连续验证。

激光与计划里程相差超过 500 mm、与短时里程预测相差超过 80 mm，须连续 3 个已接受的可信帧确认后才标记 !O；拒绝的测距不能推进该告警。编码器行程超出旧界限仍直接标记 !O。这些条件只临时限慢速，不单独报 MISMATCH / OVERRUN。!O 后控制剩余使用最后可信激光值，两帧间不让打滑里程制造虚假越程。连续 6 帧可信参考且激光剩余大于 600 mm，可解除临时限速；!O 继续提示本段里程偏差。接管后速度按可信激光剩余计算，不再被旧计划剩余永久压慢。首次/重新接管和到点确认均不累计重复 CAN 帧。

短时无可信更新最多允许 200 ms 的受限预测/保持，随后停车等待；1.5 秒仍无法恢复报 LIDAR 或 REFERENCE。墙参考用激光接近量监控进展，连续 6 秒没有累计至少 10 mm 的进展即报 NO_PROGRESS，轮子空转不能延长这个时限。持续错误或缓存的回波仍可能被接受，距离协议无法独自证明参考表面身份；须实测检查探头视线。

到点区间内输出零速，连续 2 个可信新帧确认后才切下一段。小幅越程同样先连续确认，再沿本段反方向低速回调；越程量从目标中心计算，默认最多 80 mm、回调速度最多 0.035 m/s、总回调时间最多 4 秒。真实近点回调变回接近/确认仍不重置时限，机构等待按原逻辑扣除。若连续 6 帧新可信参考均表明目标仍在前方 200 mm 以外，则退出已失效的旧回调并清除旧计时。纯里程终点仍按有效编码器到点；垄端段改为独立辅助激光确认到点，并等待底盘停稳。

墙参考的“计划长度 + 800 mm”和反向偏离起点 180 mm 改为里程可信度告警，运动仍受搜索时限、激光无进展、测距失效及 70 秒单段 / 300 秒全程超时约束。纯里程段与垄端段保留硬行程界限，超限仍报 OVERRUN D:20；激光确认的过大越程或回调超时仍触发 D:40。入口、出口仍保留纯里程定位；垄端段的最后补偿由独立围栏测距复核。

P05/P07/P09分别确认近垄端与离开事件，回溯最后近帧至第一远帧的位置区间；几何补偿仅供估计，可信前/后围栏距离负责最后到点。辅助失效最多保持200 ms旧参考，然后停车重判；已减速的换沟段不因新G后移而重新加速。

## 疏果停走握手

沿用 USART1 接收 ASCII 字符 `'1'`～`'4'` 的机构请求。导航接管后，请求先锁存到导航队列，底盘零速并确认轮速下降，再提交已有疏果任务；机构完成、成功收回且结果为成功后恢复原导航段。请求编号仍对应原工程的激光、步进和推杆。等待期间的重复请求不会排队。

这次没有实现芒果视觉识别。正式自主运行时，请求应来自车载识别模块。调试模式允许只跑路线；正式模式默认至少完成一次成功疏果，否则到 P14 显示 `NO_WORK` 并停车。

各类时间和速度以当前配置文件为准。当前机构等待上限为 600 秒、单导航段上限为 70 秒、总运行上限为 300 秒；全程超时优先，单独调大机构超时不能延长全程时限。单段时间包含该段疏果等待；多次作业时须按实际动作时间核算总预算。当前巡航上限为 0.24 m/s、慢速上限为 0.06 m/s，近点按误差继续降至最低 0.025 m/s，须上板检查速度和停车距离。完整回放包含一次 5 秒机构动作；该模型不能代替实测，多次疏果时须另核算 300 秒总预算。

## OLED 页面与排查

默认是四路激光页。长按 PE0 切到原诊断页，再长按一次进入新增流程页。

流程页出现 `D:xx` 时，表示停车条件的组合标志：01 测距无效、02 近距参考未找到、04 旧版本位置冲突标志、08 里程采样无效、10 底盘未就绪、20 纯里程/垄端硬行程超限、40 回调幅度/时间超限、80 激光自身不连续或缺少接近证据，均按十六进制显示。墙参考单纯轮式里程偏差显示 !O，不再显示旧 MISMATCH D:04/06。

调试模式启用蓝牙接口 USART2 非阻塞 VOFA，TX=PD5、RX=PD6，115200 / 8N1 / JustFloat，故障后重复发送冻结快照。原0～47编号保留，48～63追加边沿、辅助测距和控制来源，共64通道（260字节）。OLED 最后一行 Q 为可信度/拒绝码，S 为临时限速，!O 为里程告警。详见 [VOFA跑图诊断](C:/Users/user_2007/Desktop/芒果机器人/C30D-c30d-develop-import/docs/VOFA跑图诊断.md) 和 [可信度调参说明](C:/Users/user_2007/Desktop/芒果机器人/C30D-c30d-develop-import/docs/激光可信度验证与调参.md)。

```text
AT:01 GO:02 L:1
APPROACH LEFT>BACK
S:2781 G:3062 C:3/3
L: 401 T: 120 N:0/2
R: +281 Q:2/00 !O
```

- `AT`：最近到达的点；00 为尚未到 P01。`GO`：当前驶向的点。`L`：当前目标沟号。
- `LEFT>BACK`：本段动作和下一段动作。`BACK/FWD` 为倒车 / 前进，左右方向均指车身。
- 墙参考段 `S` 为本段已走编码器里程；`G` 为估计终点里程，接管前显示计划长度，接管后随可信激光更新；`C` 为捕获帧数 / 要求帧数。例如已走 2781、估计终点 3062，就应继续接近。纯里程/垄端段保持 `S:已走/终点`；垄端段辅助参考接管后，终点随可信辅助距离更新。起跑前该行仍显示里程 `X/Y`。
- `F/B/L/R`：本段实际参考的前 / 后 / 左 / 右探头；`T` 为目标读数，`N` 为不同新帧的确认次数。
- 垄端段第四行显示E:0/1/2，分别为等近垄端、等离开、已确认离开；A:B2854表示辅助后探头中值2854 mm。该段最后一行Q显示辅助参考可信度/拒绝码，确认计数见日志49/60通道。
- 正常运行最后一行 `R` 是实际控制剩余距离，负值表示越过目标；`Q` 是可信度/拒绝原因，`S` 是临时限速。!O 仅表示本段里程告警，速度可以独立恢复；此时 R 在两帧之间保持最后可信激光剩余，不必等于 G-S。原计划剩余仍可在 VOFA 通道 12 查看。等待或故障时优先显示 E/D。

| 流程状态 | 含义 |
| --- | --- |
| `WAIT` | 等待起跑；先看最后一行原因。 |
| `ODOM` | 按里程运行，尚未允许激光到点判定。 |
| `CAPTURE` | 已开放窗口，慢速寻找或连续验证近距参考；C 尚未达到要求。 |

| `RECOVER` | 已确认小幅越程，沿本段反方向低速回调。 |
| `CONFIRM` | 已停车，等待新帧确认到点或确认是否越程。 |
| `WAIT_LIDAR` | 激光失效、自身不连续或尚无到点接近证据，停车验证，默认最多 1.5 秒。 |
| `WAIT_READY` | 使能、电压或里程异常，停车等待，默认最多 5 秒。 |

| `WAIT_TOOL` | 等待机构完成并收回。 |
| `DONE` | P17 已完成，输出零速。 |
| `FAULT` | 故障终止，查看最后一行，排查后重新摆位复位。 |

| `SEG_TIMEOUT` / `RUN_TIMEOUT` | 单段 / 总运行时间超限。 |
| `TOOL_FAIL` / `TOOL_TIMEOUT` | 机构失败 / 超时，结合原机构串口结果排查。 |
| `NO_WORK` | 正式模式在完成七沟后仍没有成功疏果记录。 |
