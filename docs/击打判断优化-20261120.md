# 击打判断优化

针对既有日志中的DX±3/±4等待卡区及后距53/54毫米边界跳变，修改底盘原有状态机，不增加任务、队列或定时器。

1. WAIT/HOLD停车后，对同方向DX超界或后距中值超界累计3个新视觉快照，再重新微调；缓存快照不计数，回到有效区或方向改变会清除/重新累计。小DX横移指令最高30 mm/s。
2. 后激光取最近3个独立CAN快照的中值；同一sequence重复读取不增加样本，零值/过期清空历史。原始后距≤45毫米立即生效，原始后距不在(45,80)内禁止击打。
3. 对齐与击打使用同一次激光快照；编号确认与停稳并行。击打仍要求当前B/G和REGION有效、DX±2、后距中值47～53毫米、四轮绝对轮速≤0.005 m/s并连续合格300毫秒，且同号至少3个新帧、机构就绪、完成通知未积压。
4. 对齐后缺编号直接释放、G=0退出、通信失效处理、故障锁定、每轮最多补打一次均保留。遥控仍为480 mm/s，出现杆子或绿果任一目标则330 mm/s。

新增判定回归37项：单跳点、中值持续变化、重复CAN快照、原始45毫米优先、缓存/方向交替不重入、持续DX3微调、移动轮禁止击打及恢复后停稳300毫秒。完整击打930项、无编号释放128项、失败补打10项、超时107/606项、反向制动10项、禁用击打分支71项和减速12项回归通过，EIDE编译成功。尚未烧录/实车验证。
